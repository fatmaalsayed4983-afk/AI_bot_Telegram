# AI Telegram Assistant

نظام مساعد ذكاء اصطناعي متكامل وعالي الأداء عبر Telegram يدعم OpenAI وGoogle Gemini والبحث المتقدم في الإنترنت وتتبع الاستهلاك والذاكرة طويلة المدى.

## 📋 المتطلبات

- Python 3.10 أو أعلى
- حساب تلغرام وتوكين من BotFather
- مفتاح OpenAI API أو مفتاح Google Gemini API أو كلاهما.

## ⚙️ التثبيت والتشغيل المحلي

1. قم بإنشاء ملف البيئة الافتراضية وتفعيله:
   ```bash
   python -m venv venv
   source venv/bin/activate  # لنظام الماك/لينكس
   # أو لنظام ويندوز
   venv\Scripts\activate
   ```

2. تثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```

3. انسخ ملف الإعدادات واملأ بياناتك الخاصة:
   ```bash
   cp .env.example .env
   ```
   قم بتعبئة `TELEGRAM_BOT_TOKEN` و`OPENAI_API_KEY` و`GEMINI_API_KEY` بالقيم المناسبة.

4. تشغيل المشروع:
   ```bash
   python main.py
   ```

## 🐳 التشغيل باستخدام Docker

يمكنك تشغيل المساعد بشكل دائم على الخادم الخاص بك 24/7 دون أي مجهود:

```bash
docker-compose up --build -d
```

## 📖 الأوامر المدعومة داخل البوت

- `/start` - القائمة الرئيسية وبدء التشغيل
- `/new` - فتح نافذة ومحادثة جديدة
- `/models` - تغيير وتبديل الموديل الحالي
- `/research` - إجراء بحث عميق عبر شبكة الإنترنت وتوليد التقارير
- `/image` - توليد صور ممتازة بـ DALL-E
- `/code` - تشغيل الأكواد البرمجية مباشرة ضمن بيئة آمنة ومعزولة
- `/clear` - تفريغ ذاكرة الجلسة الحالية
- `/health` - تشخيص حالة وقابلية مكونات ومزودي النظام
- `/admin` - لوحة التحكم المخصصة للمشرفين والمسؤولين
